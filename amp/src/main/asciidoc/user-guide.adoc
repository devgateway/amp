= AMP REST API User Guide

== About

This is the reference for the AMP REST API. This API is the primary way to interact with AMP remotely, whether you
are building an app, scripting interactions with AMP or developing any other integration. This page documents the
REST resources available in AMP, along with expected HTTP response codes and sample requests.

== Authentication

REST API supports two kinds of authentications: cookie-based and token-based.

AMP itself uses cookie-based authentication in the browser, so you can call the REST API from
link:index.html[Swagger UI^] and rely on the authentication that the browser has established.

Cookie-based authentication is currently the preferred way to communicate with REST API.

[NOTE]
Token-based authentication was deprecated. If you are developing new client that connects to REST API please
consider using cookie-based authentication.

== Error handling

Most resources will return a response body in addition to the status code. Usually, the JSON object returned
has the following structure:

[source,json]
----
{
  "error": {
    "0000": [
      "(Title is required)"
    ]
  }
}
----

== Notable APIs

This section provides an overview of the most important APIs in AMP, their purpose, and major endpoints.

=== Activity API

The Activity API provides comprehensive access to activity (project) data in AMP. It allows you to retrieve, create, update, and manage activities and their related information.

==== Overall Description

The Activity API is the primary interface for working with activities in AMP. It provides endpoints for:

* Retrieving activity field definitions and possible values
* Listing activities with permission information
* Getting detailed activity information
* Creating and updating activities
* Previewing activity funding information
* Bulk importing activities

==== Major Endpoints

* `/activity/fields` - Get complete list of activity fields and their configuration
* `/activity/field/values` - Get possible values for multiple activity fields at once
* `/activity/projects` - Get a list of all activities with permission information
* `/activity/projects/{projectId}` - Get complete details of a specific activity by ID
* `/activity/` - Create a new activity by importing its data
* `/activity/{projectId}` - Update an existing activity by ID
* `/activity/{projectId}/preview/fundings` - Get activity funding information with currency conversion
* `/activity/async/bulk` - Import multiple activities in a single request (bulk import)

==== Sample Requests

Request:
[source,http]
----
GET /rest/activity/fields HTTP/1.1
Host: amp.example.org
Accept: application/json
----

Response (truncated):

  {
    "field-name": "project_title",
    "field-label": "Project Title",
    "field-type": "STRING",
    "required": true,

]

==== Overall Description

=== Contact API

The Contact API provides functionality for managing contacts in AMP, which can be associated with activities.

==== Overall Description

The Contact API allows you to retrieve, create, and update contacts in the AMP system. Contacts can be associated with activities through various relationships, such as donors, implementers, etc.

==== Major Endpoints

* `/contact/fields` - Retrieve all available contact fields with their settings and rules
* `/contact/field/values` - Returns a list of possible values for each requested field
* `/contact/{id}` - Retrieve a specific contact by ID
* `/contact/batch` - Retrieve multiple contacts by their IDs
* `/contact` - Create a new contact
* `/contact/{id}` - Update an existing contact

==== Interaction with Activity Endpoints

Contacts interact with activities in several ways:

* Contacts can be associated with activities through various roles (donor contacts, implementing agency contacts, etc.)
* The Activity API uses contact IDs to reference contacts in activity data
* When creating or updating activities, you can include references to existing contacts or create new contacts

=== Data (Reports) API

The Data API provides access to AMP's reporting functionality, allowing you to retrieve and export data reports.

==== Overall Description

The Reports API allows you to work with AMP reports, including:

* Retrieving report definitions
* Generating reports in various formats
* Exporting reports to different file formats
* Managing report tabs and settings

==== Major Endpoints

* `/reports/{reportId}` - Get report definition and data
* `/reports/report/result` - Get report results based on parameters
* `/reports/report/excel` - Generate Excel report
* `/reports/saiku/{reportId}` - Get Saiku-based report
* `/reports/saiku/export/xls/{reportId}` - Export report to Excel
* `/reports/saiku/export/csv/{reportId}` - Export report to CSV
* `/reports/saiku/export/xml/{reportId}` - Export report to XML
* `/reports/saiku/export/pdf/{reportId}` - Export report to PDF
